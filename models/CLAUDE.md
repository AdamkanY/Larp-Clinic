# models/

Saved trained models (`.joblib`) and their metrics. Not for: training code or data. Every model file needs a
matching metrics file recording ROC-AUC, PR-AUC, the split dates and the feature list.

Everything here is regenerated by `python src/train.py` (tune + fit + evaluate) or, for the test-time outputs
only, `python src/evaluate.py`. Do not edit by hand. Load models through `src/predict.py` (`load_model`,
`score`, `percentile`), never with a hard-coded path.

| File | Contains | Produced by | Used by |
|---|---|---|---|
| `gbm.joblib` | **App model.** `CalibratedClassifierCV(method='isotonic', cv=5)` around the tuned GBM pipeline, fitted on train; `predict_proba` averages the 5 calibrated fold copies | `src/train.py` | `src/predict.py` (`score`), `app/` |
| `gbm_uncalibrated.joblib` | The tuned GBM pipeline itself: ordinal-coded categoricals + `HistGradientBoostingClassifier(class_weight='balanced')`, native categorical splits. Kept for the before/after comparison and as the ablation reference | `src/train.py` | `src/evaluate.py` |
| `baseline_lr.joblib` | sklearn Pipeline: impute/scale/one-hot + `LogisticRegression(class_weight='balanced')` (uncalibrated) | `src/train.py` | `src/evaluate.py` |
| `<model>_metrics.json` (one per `.joblib`) | Split dates and sizes, feature list, CV grid + best params, F1 threshold and OOF metrics (from out-of-fold train predictions), test ROC-AUC / PR-AUC / Brier, confusion matrix at that threshold, calibration bins, majority baseline, sklearn version. `gbm_metrics.json` adds `calibration` (test Brier before/after), `score_reference` and `ablations` | `src/train.py` (train/CV parts), `src/evaluate.py` (`test`, `majority_baseline`, `calibration.test_*`, `ablations`) | `app/` (`gbm_metrics.json` only), report |
| `score_reference.npy` | Sorted out-of-fold calibrated scores of the 114,600 train trials (start 2008-2016); the reference for `percentile()` | `src/train.py` | `src/predict.py` (`percentile`), `app/risk_gauge.py` (risk colour and comparison bar; reads the file itself) |
| `calibration_before_after.png` | GBM calibration curve + prediction histogram on test, before vs after isotonic calibration | `src/evaluate.py` | report, video |
| `feature_importance.csv` | Permutation importance on test for `baseline_lr` and `gbm`, one row per model x raw feature: mean/std drop in ROC-AUC and PR-AUC, `rank` by ROC-AUC drop | `src/evaluate.py` | `app/` (driver charts), report |

## Ablations: post-registration edits

The API returns each record's latest version, so features a sponsor can amend after the start might carry
post-start information. The GBM was refitted on train without them (same hyperparameters, uncalibrated, so the
reference is `gbm_uncalibrated`). Losing them costs under 0.01 ROC-AUC, so the model does not depend on them.

| Variant | Features | CV ROC-AUC (train) | Test ROC-AUC | Δ test ROC-AUC | Test PR-AUC |
|---|---|---|---|---|---|
| All features | 29 | 0.710 | 0.709 | – | 0.233 |
| Without `eligibility_text_len` | 28 | 0.703 | 0.701 | -0.008 | 0.229 |
| Without `n_primary_outcomes`, `n_secondary_outcomes` | 27 | 0.707 | 0.708 | -0.001 | 0.231 |
| Without all three | 26 | 0.701 | 0.701 | -0.009 | 0.229 |

## Notes

- `score()` returns the **calibrated** probability. On train (out-of-fold) the mean score equals the terminated rate
  (0.111). On test it is 0.099 vs an observed 0.117: 2017-2019 trials look lower-risk on paper (more phase-NA,
  behavioural and healthy-volunteer studies) yet terminated slightly more often. Expect the same downward bias
  for recent and ongoing trials.
- `baseline_lr` and `gbm_uncalibrated` probabilities are inflated by `class_weight='balanced'`; use them for
  ranking only.
- `.joblib` files only load reliably with the sklearn version in `sklearn_version` of the metrics JSON
  (`requirements.txt` pins it). Retrain if you change the pin.
