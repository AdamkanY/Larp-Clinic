# models/

Saved trained models (`.joblib`) and their metrics. Not for: training code or data. Every model file needs a
matching metrics file recording ROC-AUC, PR-AUC, the split dates and the feature list.

Everything here is regenerated by `python src/train.py` (tune + fit + evaluate) or, for the test-time outputs
only, `python src/evaluate.py`. Do not edit by hand. Load models through `src/predict.py` (`load_model`,
`score`), never with a hard-coded path.

| File | Contains | Produced by | Used by |
|---|---|---|---|
| `baseline_lr.joblib` | sklearn Pipeline: impute/scale/one-hot + `LogisticRegression(class_weight='balanced')` | `src/train.py` | `src/evaluate.py`, `app/` (explanations) |
| `gbm.joblib` | sklearn Pipeline: ordinal-coded categoricals + `HistGradientBoostingClassifier(class_weight='balanced')`, native categorical splits. **Default model for the app** | `src/train.py` | `src/predict.py`, `app/` |
| `baseline_lr_metrics.json`, `gbm_metrics.json` | Split dates and sizes, feature list, CV grid + best params, F1 threshold (from out-of-fold train predictions), test ROC-AUC / PR-AUC / Brier, confusion matrix at that threshold, calibration bins, majority baseline, sklearn version | `src/train.py` (train/CV parts), `src/evaluate.py` (`test`, `majority_baseline`) | `app/`, report |
| `calibration_curve.png` | Calibration curve + prediction histogram of both models on the test split | `src/evaluate.py` | report, video |
| `feature_importance.csv` | Permutation importance on test, one row per model x raw feature: mean/std drop in ROC-AUC and PR-AUC, `rank` by ROC-AUC drop | `src/evaluate.py` | `app/` (driver charts), report |

## Notes

- Probabilities are **not calibrated**: `class_weight='balanced'` inflates them (see the calibration plot). Use
  them to rank and compare trials. Before showing a percentage as "chance of termination", calibrate (e.g.
  `CalibratedClassifierCV` with CV on train).
- `.joblib` files only load reliably with the sklearn version in `sklearn_version` of the metrics JSON.
  Retrain if the deployed environment differs.
