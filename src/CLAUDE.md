# src/

Reusable Python for data fetching, feature building, model training and the ClinicalTrials.gov API client.
Not for: Streamlit code (`app/`), exploration (`notebooks/`), data files or saved models.
Must not import from `app/` or `notebooks/`. Rules in the root `CLAUDE.md` (label, leakage, date split) apply to
everything here.

Pipeline: `python src/fetch_data.py`, then `python src/build_dataset.py`, then `python src/train.py`
(tunes, fits, saves and evaluates all models; `python src/evaluate.py` re-runs only the test evaluation).
`python src/build_dataset.py --backfill` adds derived feature columns to an existing parquet without raw pages.

Feature versions: **v1** = the 29 features of PR #4 (`V1_FEATURE_COLUMNS`), **v2** = all 39 `FEATURE_COLUMNS`
(v1 + `cond_*` flags, `n_condition_categories`, `n_intervention_types`). The app model `gbm` stays v1 because v2
missed the decision rule (+0.005 ROC-AUC on test AND in CV); v2 is trained the same way as challenger `gbm_v2`.

| File | Contains / does | Produced by | Used by |
|---|---|---|---|
| `fetch_data.py` | Downloads all INTERVENTIONAL COMPLETED/TERMINATED studies from the API v2 into `data/raw/pages/` (resumable, retry/backoff, progress; projection also fetches `BriefTitle`, `LeadSponsorName` for display) | Simon | `build_dataset.py` |
| `features.py` | `build_features(study_json) -> dict`: the single feature function (design-time fields only) plus column lists. Absent lists count as 0; missing max age = 120 with `has_max_age` flag; no `start_year`/`fda_regulated_*` features. `condition_features(conditions: list[str]) -> dict` (called by `build_features`): keyword rules per semicolon-separated clause -> multi-hot `cond_oncology/cardio/neuro/infectious/metabolic/psych/respiratory/healthy` + `n_condition_categories`; organ words (lung, brain) do not count inside a tumour clause; result depends only on the `"; "`-joined text, so the parquet backfill equals `build_features`. `n_intervention_types` = distinct enum intervention types. New columns sit at the end of `BINARY_FEATURES` / `NUMERIC_FEATURES`; `V2_FEATURES` lists them, `V1_FEATURE_COLUMNS` = the PR #4 features in their old order. `DISPLAY_COLS` = app-only columns (title, conditions, sponsor name, phase label), never model inputs | Simon / Adam | `build_dataset.py`, `train.py`, `app/` |
| `build_dataset.py` | Runs `build_features` over raw pages, applies label and 2008-2019 window, adds `split`, writes `data/processed/trials.parquet`, prints counts and the terminated rate per condition category. `--backfill` recomputes the derived columns (`cond_*` from the stored `conditions` split on `"; "`, `n_intervention_types` from the intervention flags) in the existing parquet, keeping rows and all other values | Simon / Adam | `train.py`, app visuals |
| `viz.py` | Explore-dashboard helpers: `load_trials` (adds `start_year`, `outcome`, fills missing categories with "Unknown"), `filter_trials`, `rate_by`, `top_conditions`, Plotly figure builders, `trials_table`. Pure pandas/Plotly, no Streamlit, no model | Adam | `app/pages/2_Explore.py` |
| `train.py` | Loads `trials.parquet` and checks label / window / split rules, builds the LR and GBM Pipelines (`features=` picks the columns; each model is fitted on exactly its own columns), tunes each by 5-fold stratified CV on train (refit on PR-AUC; best cell's per-fold scores kept), wraps the tuned GBM in `CalibratedClassifierCV(method='isotonic', cv=5)` fitted on train, picks each model's F1-max threshold on out-of-fold train predictions, saves `models/<name>.joblib` + `<name>_metrics.json` (with that model's feature list) and `score_reference.npy` (OOF calibrated scores). App model and baselines use `APP_FEATURES` (v1); `CHALLENGERS` (`gbm_v2`: all 39 features) get the identical tuning + calibration. Then calls `evaluate.evaluate_saved`. `build_gbm_pipeline(drop=...)` serves the ablations | Adam | CLI, `evaluate.py` |
| `evaluate.py` | The only code that scores the test split: test ROC-AUC / PR-AUC / Brier, confusion matrix at the stored threshold, majority baseline, `version_comparison` of each challenger vs `gbm` (CV / OOF / test metrics, per-fold CV gains, paired bootstrap CI of the test ROC-AUC gain, `MIN_ROC_AUC_GAIN = 0.005` rule), calibration before/after (JSON + plot), permutation importance CSV (`baseline_lr`, `gbm`, `gbm_v2`, each over its own columns), LR coefficients, and the GBM feature ablations (refit on train without post-registration-editable features, scored once on test). Matplotlib is imported lazily, only for the plot | Adam / Dominic | `train.py`, CLI, `app/` |
| `predict.py` | `load_model(path='models/gbm.joblib')`, `score(features: dict) -> float` (**calibrated** P(TERMINATED)), `percentile(prob) -> float` (0-100: share of training trials with a lower out-of-fold score), `to_model_frame` (the single dict/DataFrame -> `FEATURE_COLUMNS` frame used by training and the app) and `model_columns(model)` (the columns a model was fitted on; `score` passes only those, so v1 and v2 models both work). No sklearn-training or plotting imports | Adam | `app/`, `train.py`, `evaluate.py` |
| `api_client.py` | Live ClinicalTrials.gov API v2 client for the app: `search_trials(query, status, page_size, phase, condition, sponsor_class)` and `get_trial(nct_id)` (never raise, errors come back as values; successful responses are cached 1 h through a private `_get_json` helper that raises on failure, so errors are never cached), `summarize(study)` for the results table. Imports streamlit only for caching. Full records from `get_trial` go to `build_features` | Matteo | `app/pages/1_Search.py` |
