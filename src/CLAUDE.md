# src/

Reusable Python for data fetching, feature building, model training and the ClinicalTrials.gov API client.
Not for: Streamlit code (`app/`), exploration (`notebooks/`), data files or saved models.
Must not import from `app/` or `notebooks/`. Rules in the root `CLAUDE.md` (label, leakage, date split) apply to
everything here; the only exception is the horizon experiment (`horizon.py`, `train_horizon.py`), bounded as the
root guide says.

Pipeline: `python src/fetch_data.py`, then `python src/build_dataset.py`, then `python src/train.py`
(tunes, fits, saves and evaluates both models; `python src/evaluate.py` re-runs only the test evaluation).
Horizon experiment: `python src/train_horizon.py` after the same two data steps (never changes the app model).

| File | Contains / does | Produced by | Used by |
|---|---|---|---|
| `fetch_data.py` | Downloads INTERVENTIONAL studies from the API v2 into `data/raw/pages/`: COMPLETED/TERMINATED plus the still-running statuses (`STATUSES`). Resumable, retry/backoff, progress. The projection (`FIELDS`) also fetches `BriefTitle`, `LeadSponsorName` for display and `CompletionDate`, `CompletionDateType`, `WhyStopped` for `horizon.py` only; `manifest.json` records `fetched_on` | Simon | `build_dataset.py` |
| `features.py` | `build_features(study_json) -> dict`: the single feature function (design-time fields only) plus column lists. Absent lists count as 0; missing max age = 120 with `has_max_age` flag; no `start_year`/`fda_regulated_*` features. `DISPLAY_COLS` = app-only columns (title, conditions, sponsor name, phase label), never model inputs | Simon / Adam | `build_dataset.py`, `train.py`, `app/` |
| `build_dataset.py` | Reads the raw pages once (`build_features` rows plus `horizon.outcome_fields`). Writes `trials.parquet` exactly as before (status label, 2008-2019 window, train/test `split`), then, if the download has still-running trials and the completion fields (`horizon_problem`), `trials_3y.parquet` (`build_horizon_dataset`: horizon label, train/valid/test, no outcome columns, snapshot in `df.attrs`) and `outcomes.parquet` (`build_outcomes`, charts only). Prints counts and drop reasons. `--horizon-only`, `--snapshot` | Simon | `train.py`, `train_horizon.py`, app visuals |
| `horizon.py` | The 3-year horizon label and the only reader of outcome fields: `outcome_fields(study)` (completion date and type, `whyStopped`), `horizon_labels(df, snapshot)` (1 = terminated within 36 months of the start month; 0 = completed, stopped later or still running; missing for other statuses, unusable stop dates and starts after `followup_cutoff` = download date - 3 years - `REPORTING_LAG_MONTHS`), `months_to_stop` / `years_to_stop`, `split_for` (`SPLITS`: train 2008-2018, valid 2019, test 2020+), `stop_reason` (rough keyword groups, COVID first), `mentions_covid`, `OUTCOME_COLUMNS` (never allowed in a training file). Pure pandas | Adam | `build_dataset.py`, `train_horizon.py`, tests |
| `train_horizon.py` | **Experiment, not the app model.** Trains `train.py`'s pipelines, grids, CV, calibration and threshold rule on `trials_3y.parquet`; `check_dataset` refuses outcome columns, wrong splits or a missing cutoff. Scores valid (2019, before COVID) and test (2020+) once: every model plus two references against the same horizon labels (the app model as it is, and the GBM refitted on the status label of the same years), per start year, and feature drift train vs test. Writes `models/horizon_3y/` (`--phases 1-3`: `models/horizon_3y_phase1-3/`). `run(...)` is the testable entry | Adam / Dominic | CLI, `tests/test_train_horizon.py` |
| `viz.py` | Explore-page helpers: `load_trials` (adds `start_year`, `outcome`, `eligibility_group`; turns codes into plain names through `labels.py`; missing values become "Not stated"), `filter_trials`, `rate_by`, `extremes` (highest/lowest group in words), `top_conditions`, Plotly figure builders (`rate_bar`, `rate_over_time`, `conditions_bar`, `eligibility_stats`), `trials_table`, and the chart look shared with the app pages (`BAR`, `INK`, `MUTED`, `CHART_LAYOUT`, `finish(fig)`). Follow-up and COVID charts on `outcomes.parquet`: `load_outcomes` (adds start/stop year and status group; `path=None` reads `OUTCOMES_PATH` at call time), `followup_by_year` + `followup_chart` (share stopped early among ended trials vs within 3 years among all, unfollowed years shaded), `not_ended_chart`, `covid_by_stop_year` + `covid_chart`, `time_to_stop` + `time_to_stop_chart`, `stop_reasons` + `stop_reasons_chart`. Pure pandas/Plotly, no Streamlit, no model | Adam / Matteo | `app/pages/2_Explore.py` |
| `train.py` | Loads `trials.parquet` and checks label / window / split rules, builds the LR and GBM Pipelines, tunes each by 5-fold stratified CV on train (refit on PR-AUC), wraps the tuned GBM in `CalibratedClassifierCV(method='isotonic', cv=5)` fitted on train, picks each model's F1-max threshold on out-of-fold train predictions, saves `models/<name>.joblib` + `<name>_metrics.json` and `score_reference.npy` (OOF calibrated scores), then calls `evaluate.evaluate_saved`. `build_gbm_pipeline(drop=...)` serves the ablations | Adam | CLI, `evaluate.py` |
| `evaluate.py` | The only code that scores the test split: test ROC-AUC / PR-AUC / Brier, confusion matrix at the stored threshold, majority baseline, calibration before/after (JSON + plot), permutation importance CSV, LR coefficients, and the GBM feature ablations (refit on train without post-registration-editable features, scored once on test). Matplotlib is imported lazily, only for the plot | Adam / Dominic | `train.py`, CLI, `app/` |
| `predict.py` | `load_model(path='models/gbm.joblib')`, `score(features: dict) -> float` (**calibrated** P(TERMINATED)), `percentile(prob) -> float` (0-100: share of training trials with a lower out-of-fold score) and `to_model_frame`, the single dict/DataFrame -> model-input conversion used by training and the app. No sklearn-training or plotting imports | Adam | `app/`, `train.py`, `evaluate.py` |
| `api_client.py` | Live ClinicalTrials.gov API v2 client for the app: `search_trials(query, status, page_size, phase, condition, sponsor_class)` (ongoing statuses incl. enrolling by invitation, **interventional studies only**: the model learned from those) and `get_trial(nct_id)` (never raise, errors come back as values; successful responses are cached 1 h through a private `_get_json` helper that raises on failure, so errors are never cached), `summarize(study)` for result cards. Imports streamlit only for caching. Full records go to `build_features` | Matteo | `app/pages/1_Search.py` |
| `labels.py` | Plain-English names for API codes and data values (`label(kind, code)`: "DOUBLE" -> "Double blind", every spelling of "no phase" -> "No phase", gaps -> "Not stated"). One place so every page uses the same words. Pure Python | Matteo | `app/`, `viz.py` |
