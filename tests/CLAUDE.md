# tests/

Offline checks: no network, no live API. Run each file with `python tests/<file>` from the repo root.
Not for: exploration or tests that call the live API.

| File | Contains | Produced by | Used by |
|---|---|---|---|
| `test_features.py` | Checks `build_features` values, missing handling, and that leaky fields (enrollment, locations, results, other dates) are ignored; `condition_features` (keywords, multi-hot, word starts, missing lists) and that `--backfill` gives the same flags; `features_from_design` gives exactly the features of the equivalent API record. Synthetic records only | Simon / Adam | everyone, before committing feature changes |
| `test_predict.py` | `explain()` on a small model fitted to an invented table with known drivers (right order, direction, plain names, nothing for a typical trial, max age and its flag as one factor), `model_features` / `to_model_frame` column handling, `score_frame` equal to `score` and ignoring extra columns, a plain name for every feature in `labels.py`, plus one run on the saved model (skipped if `models/` files are missing) | Adam | everyone, before committing changes to `src/predict.py`, `features.py` or `labels.py` |
| `test_app.py` | Helper code of the app: plain names (`labels.py`), chart data and filters (`viz.py`, on an invented table), the game's pair sampler and scoring (`game.py`, invented table and a stub model; one check against `predict.score` needs the real model), the API client (stubbed `requests.get`: interventional filter, retry after a failure, caching of successes) and the risk colours. Needs `models/score_reference.npy` for the colour check, otherwise skips it | Matteo | everyone, before committing changes to `app/` or `src/` |
| `test_pages.py` | Opens every page in Streamlit's test runner and clicks through the main paths (filter and clear in Explore; reset, drivers chart, design-only levers, condition recognition and the model-mismatch message in Check; result cards, details and drivers chart in Search with an invented record, offline message; tabs in Explain; ten rounds of the game through to "Play again"). Needs the real `data/processed/trials.parquet` and `models/` files; prints "skipped" if they are missing | Matteo | everyone, before committing changes to `app/` |
